เว็บไซต์แนะนำหลักสูตรวิทยาการคอมพิวเตอร์เปิดให้บริการแล้ว! เว็บนี้เป็นผลงานกลุ่มของนักศึกษาในวิชาเครือข่ายคอมพิวเตอร์ ที่ลงมือติดตั้งทุกอย่างเองบนเซิร์ฟเวอร์คลาวด์

เบื้องหลังเว็บนี้

  • Nginx + PHP-FPM + MySQL 8 + WordPress บน Ubuntu 24.04
  • HTTPS ด้วยใบรับรองจาก Let's Encrypt (ต่ออายุอัตโนมัติ)
  • SSH แบบ public key เท่านั้น และ firewall ที่เปิดให้เข้าได้เฉพาะจากประเทศไทย
